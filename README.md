### ANACODA ENVIRONMENT CONFIGURATION

- This project was programmed and tested with anaconda. To set up the environment, ensure that you have anaconda installed on your machine.

- Ensure you have executed: ```conda init bash/zsh/powershell``` before setup.

- There is a provided _setup.sh_/_setup.bat_ file that will make the conda environment according to the _qiskit-env.yml_ for you.

- Once such an environment has been instantiated, any python file may be ran as normal.
